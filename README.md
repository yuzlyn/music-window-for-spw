# 音乐浮窗（Music Island for SPW）

给 Salt Player for Windows 加一个 Windows 11 / Fluent 风格的桌面音乐浮窗：

- 左侧方形封面 + 右侧实时歌词与进度条
- 点击封面展开 / 收起；收起可切换「圆形专辑封面」或「长条胶囊」
- 波浪之外的 Fluent 细进度条，支持点击与拖动跳转
- 独立曲库窗口（支持中文输入法搜索）
- 系统托盘图标与菜单
- 全屏应用时可选自动隐藏
- 动画优先 / 性能优先两种模式

## 环境要求

- Salt Player for Windows `1.19.0` 及以上
- 插件权限：`library-read`（封面、歌词、曲库）、`key-bindings`（全局快捷键）

## 安装

1. 下载 Release 中的 `plugin-io.github.spw.island-x.y.z.spmod`
2. 播放器 → 创意工坊 → 模组管理 → 导入模组
3. 启用并授予上述权限
4. 右下角出现浮窗；托盘出现音符图标

## 使用

| 操作 | 效果 |
|---|---|
| 点击封面 | 展开 / 收起 |
| 悬停歌词 | 显示歌名与艺术家 |
| 点进度条 / 拖动 | 跳转播放位置 |
| 拖窗口任意空白处 | 移动窗口（贴边自动回位） |
| 托盘左键双击 | 显示 / 隐藏浮窗 |
| 托盘右键 | 显示隐藏、打开曲库、全屏隐藏、关闭 |

## 配置项

**外观**：强调色（Windows 11 六色）、明暗模式、歌词字号、显示封面 / 歌词行 / 翻译
**行为**：动画模式（动画优先 / 性能优先）、全屏时自动隐藏、收起样式（专辑封面 / 胶囊）、启动时收起、置顶、窗口不透明度
**操作**：显示浮窗、打开曲库、查看当前状态

## 实现说明

- 浮窗使用离屏渲染（Compose `ImageComposeScene` → `BufferedImage` → `JWindow` 贴图），
  移动窗口时不触发任何布局或重绘，因此拖动不会掉帧；
- 曲库窗口使用真实 `ComposePanel`，以支持输入法；
- 不修改宿主界面，不需要 `class-transform` 权限。

## 已知限制

- 曲库列表仅用于浏览：当前 Workshop API 不提供「按歌曲 ID 播放」，点选不会切歌；
- 全屏检测基于前台窗口是否覆盖主屏，独占全屏游戏可能误判；
- 收起 / 展开的圆角是窗口级裁剪，为换取拖动流畅度，没有做抗锯齿。

## 构建

```bash
./gradlew plugin
# 产物：build/libs/plugin-io.github.spw.island-<version>.spmod
```

需要 JDK 25（可用 `JAVA_HOME` 指定）。
